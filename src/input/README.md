# input [![Crates.io](https://img.shields.io/crates/v/piston.svg?style=flat-square)](https://crates.io/crates/piston)

A structure for user input.

This library contains:

* Press and release of buttons
* Keyboard
* Mouse
* Unicode input
* Window resize
* Window focus
* Modifier keys

### Serialization

Serde is enabled behind the feature flag "serde".

When you run tests on this library, use the following:

```text
cargo test --features test
```
